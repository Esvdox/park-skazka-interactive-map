# Интерактивная карта Парка «Сказка»

Рабочий статический прототип, построенный только по `Сказка по слоям .psd`.

## Что реализовано

- текущая композиция PSD используется как постоянная базовая карта;
- 70 скрытых непустых слоёв из группы `Группа 1` экспортированы как отдельные WebP-оверлеи;
- правая экспликация и QR-блоки убраны из карты crop-областью 3200×1939;
- 67 объектов получили справочник номеров и отображаемых названий из подтверждённого сопоставления;
- при наведении на область объекта показывается tooltip `номер + название` даже для закрытого слоя;
- слой показывается полноцветным только при статусе `open`;
- при `maintenance`, `closed`, `weather_hold` или `unknown` оверлей скрыт, поэтому видна полупрозрачная версия объекта в базе;
- доступны поиск, фильтр статусов, ручное переключение для проверки, масштабирование и перемещение карты;
- карта, поиск и настройка параметров разделены на отдельные вкладки;
- на карте доступны температурные пресеты `Выше 0`, `−5`, `−10`, `−15`; порог слоя задаётся в параметрах;
- для слоя можно задать название, условия работы, минимальную температуру и дополнительные пары параметров;
- проект не требует серверного фреймворка и подходит для GitHub Pages.

## Локальный запуск

```powershell
python -m http.server 8080 --directory interactive-map-prototype
```

Открыть `http://localhost:8080/`.

## Обновление из PSD

```powershell
python tools\export_interactive_layers.py `
  "C:\Users\sivanov\Desktop\Сказка по слоям .psd" `
  "." `
  --crop-right 3200 `
  --exclude-layer-id layer-036-71c999f7d1
```

Экспортёр выбирает скрытые непустые конечные слои группы `Группа 1`. Уже видимые слои остаются частью базовой карты. Идентификаторы строятся из позиции и полного пути слоя, поэтому одинаковые названия не конфликтуют.

Проверка экспорта:

```powershell
python tools\validate_interactive_export.py .
```

## Статусы

Публичный фронтенд читает `data/status.json`. Допустимые значения:

- `open` — показать полноцветный слой;
- `maintenance` — техническое обслуживание;
- `closed` — закрыт по операционной причине;
- `weather_hold` — остановлен по погоде;
- `unknown` — нет подтверждённых данных, оверлей скрыт.

Ручные статусы и настройки слоя служат для проверки и сохраняются только в `localStorage` этого браузера; на сервер они не записываются.

## Публикация

Содержимое каталога можно разместить в публичном репозитории и включить GitHub Pages из ветки `main` или каталога `/docs`. Публикация и создание внешнего репозитория не выполнялись автоматически.
