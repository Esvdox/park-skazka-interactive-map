# Контракт публичных статусов

```json
{
  "schemaVersion": 1,
  "generatedAt": "2026-10-01T12:00:00Z",
  "items": [
    {
      "id": "layer-000-0000000000",
      "status": "open",
      "source": "toir",
      "updatedAt": "2026-10-01T11:59:20Z",
      "validUntil": "2026-10-01T12:04:20Z"
    }
  ]
}
```

Обязательные поля элемента: `id`, `status`, `source`, `updatedAt`. Поле `validUntil` рекомендуется для автоматического перехода в `unknown` после потери связи.

Допустимые статусы: `open`, `maintenance`, `closed`, `weather_hold`, `unknown`.

В публичный файл нельзя включать ФИО сотрудников, номера заявок с внутренними комментариями, причины неисправностей, токены и адреса внутренних API.
