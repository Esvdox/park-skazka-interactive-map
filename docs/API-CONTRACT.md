# API статусов условий карты

GitHub Pages остается только клиентом. Для подключения системы ТОиР или другой операционной
системы перед загрузкой страницы нужно задать:

```html
<script>window.PARK_MAP_API_BASE = "https://api.example.ru";</script>
```

## Условия слоя

`PUT /api/v1/map/layers/{layerId}/conditions`

Тело запроса:

```json
{
  "maintenance": false,
  "rain": true,
  "repair": false
}
```

Значение `true` означает, что условие присутствует у слоя: объект находится на ТО, работает
в дождь или находится в ремонте. При включении соответствующего фильтра такой объект скрывается.
Фронтенд преобразует значения в поля `Да / Нет` в параметрах слоя.

Ответ: `200 OK` с сохраненным объектом и полями `layerId`, `updatedAt`, `source`.

## Текущие условия

Рекомендуемый endpoint для синхронизации:

`GET /api/v1/map/layer-conditions`

```json
{
  "schemaVersion": 1,
  "generatedAt": "2026-10-02T12:00:00Z",
  "items": [
    {
      "layerId": "layer-031-90916546ff",
      "maintenance": false,
      "rain": true,
      "repair": false,
      "updatedAt": "2026-10-02T11:59:00Z",
      "source": "toir"
    }
  ]
}
```

API должна проверять авторизацию, права записи, `layerId`, журналировать изменения и отдавать
только безопасные для публичной карты поля. Адрес реальной системы ТОиР и токены в репозиторий
не добавляются.
