# Карта постановлений — Парк «Сказка»

Публичная интерактивная оцифровка предоставленной схемы объектов по 636-ПП и 529-ПП, без НТО. Исходный TIFF не изменён и не включён в Git: вместо него опубликован полностью идентичный по RGB-пикселям WebP без потерь.

88 строк исходной экспликации: 30 аттракционов по 636-ПП, 4 открытые интерактивные площадки по 636-ПП, 34 объекта по 529-ПП и 20 объектов, связь которых с постановлением в легенде не указана. Названия и номера сохранены. Номер объекта не равен количеству сооружений: в исходнике встречаются повторные метки.

Поиск по номеру/названию, категории с повторным нажатием для сброса, карточки, переход к оцифрованным вхождениям номера, масштабирование до 400%, перемещение, жест двумя пальцами, клавиатура, полноэкранный просмотр, исходная схема, экспликация и CSV.

## Ограничения

- Только сведения исходной схемы: правовая применимость, действующие редакции постановлений, разрешения и кадастровые сведения не исследовались. Дата схемы не указана.
- Геопривязки нет; координаты номерных меток вручную оцифрованы приблизительно. Дополнительные повторные метки могут присутствовать на растровом оригинале. Для определения точного расположения сверяйтесь с исходной схемой.
- Фильтры управляют интерактивными метками и реестром. Цветная растровая подложка остаётся видимой, отдельные векторные контуры объектов не создавались.
- Названия вроде «Аттракцион №1» не заменены неподтверждёнными именами. «MOTOR CITY» и «VR» являются исходными названиями.

## Воспроизведение

Python + Pillow: `python tools/build.py <путь-к-исходному-TIFF>`. Скрипт проверяет размер, единственную страницу, полное совпадение пикселей экспортов, 88 объектов и наличие меток для каждой строки. SHA-256 TIFF записан в `data/objects.json`. Иные документы проекта не включены в эту публикацию.

Для локального просмотра: `python -m http.server 8080` из корня репозитория, страница `/decrees/`. Серверные записи, внешняя аналитика и API отсутствуют.

## Мобильная версия

До 900 px доступны отдельные экраны «Карта», «Объекты», «Сведения». Поиск переводит к выбранному объекту и открывает нижнюю карточку; в альбомной ориентации карточка располагается справа. Кнопки имеют сенсорные зоны от 44 px, поля ввода — 16 px, предусмотрены safe-area и высота динамического viewport. Масштаб и положение сохраняются между вкладками; поворот экрана сохраняет масштаб просмотра. Перетаскивание работает и при начале жеста на номерной метке; движение не открывает карточку. Два указателя изменяют масштаб и положение карты.

Мобильные жесты: один палец прокручивает всю страницу по вертикали, включая полный список объектов, и не меняет положение/масштаб подложки. Два пальца перемещают и масштабируют карту. Нижнее меню резервирует место вне визуала, учтены safe-area и стабильная высота `svh`. Регрессия жестов: `node decrees/tests/gestures.cjs` из корня репозитория.
